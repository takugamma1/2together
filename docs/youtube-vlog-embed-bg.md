# Как да добавиш YouTube влога (за Калин)

Клипът излиза на 23 август, 19:00. Има три места, където линкът се слага на ръка — всичките са в **Online Store → Themes → Customize** (редактора на темата), без код.

## 1. Рампи — бутонът „Гледай влога“ и „30-секундната трансформация“
1. Отвори редактора → горе в падащото меню избери **Pages → Portable Ramps**.
2. Кликни секцията **Portable Ramps** вляво.
3. Секция **08 · Story** → поле **Video link** → постави линка на клипа (`https://www.youtube.com/watch?v=…`).
4. Секция **05 · Transformation** → поле **Video link** → същият или друг клип.
5. **Save** горе вдясно. Бутонът „Гледай влога“ се появява само когато има линк.

## 2. Продуктовите страници BREEZE / STORM — „Виж скокове с този модел“
1. **Products → BREEZE** (или STORM) → вдясно **Tags**.
2. Добави таг `video:https://www.youtube.com/watch?v=…` → **Save**. (Тагът важи само за тази страница; двете рампи могат да имат различни клипове.)

## 3. Начална страница — „Последни клипове“
Каруселът се пълни автоматично от канала на клуба (`/apps/club/youtube`). Ако новият клип не се появи до час след публикуването:
1. Редактор → **Home page** → секция **YouTube carousel** → провери полето **Channel URL** (линк към канала).
2. **Save**.

## 4. В блог статия (по желание)
**Content → Blog posts → Add blog post** → в редактора на текста бутонът **Insert video** (иконата с камерата) → постави YouTube линка → **Insert** → **Save** и сложи снимка за корица. Статията се показва автоматично в блок „Истории от клуба“ на началната страница.

### Къде намираш линка в YouTube
Отвори клипа → **Share** → копирай линка (`https://youtu.be/…` или `https://www.youtube.com/watch?v=…`). И двата формата работят.
